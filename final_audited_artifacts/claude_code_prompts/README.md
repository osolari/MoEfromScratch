# Claude Code prompts for *MoE Models from Scratch*

Use these prompt files with `HOWTOEDIT.md`. The intended workflow is setup once, then develop one section at a time, then run chapter integration and review passes.

Recommended order:

1. `01_setup_and_protocol_prompt.md`
2. `02_section_development_prompt.md` for each section
3. `03_chapter_integration_prompt.md` after each chapter
4. `04_chapter_review_prompt.md` in a separate review session
5. `05_final_whole_book_audit_prompt.md` after all chapters are complete
6. `06_git_worktree_parallel_prompt.md` when working in parallel by chapter

Copy `CLAUDE.md` to the repo root before starting Claude Code.
