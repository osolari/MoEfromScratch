# Source inventory extracted for Phase 2

## Parsed source files

- EPUB chapter XHTML: 8 chapter files.
- Stylesheet: `OEBPS/Styles/stylesheet.css`.
- Image assets: 225 files.

## Generated data files

| File | Purpose |
|---|---|
| `data/chapter_metrics.csv` | Chapter-level counts and paragraph metrics. |
| `data/chapter_outline.json` | Chapter titles, opening bullets, and top-level section headings. |
| `data/figure_inventory.csv` | Figure count, image file, dimensions, and high-level caption role. |
| `data/listing_inventory.csv` | Listing/code-block counts, language hints, and annotation counts. |
| `data/table_inventory.csv` | Table dimensions and header hints. |
| `data/callout_inventory.csv` | Callout roles and word-count scale. |
| `data/image_dimensions.csv` | Raw image dimensions and aspect ratios. |

## Notes

The generated inventories intentionally avoid reproducing long source captions or prose. They are intended to support layout, style, and planning decisions for the new LaTeX book.
