    2.3 Causal self-attention as the context path¶

    Section 2.2 produced a \((B, T, D)\) sequence in which every position carries its own embedded representation but no two positions can yet see each other. A decoder language model needs exactly one path that mixes information across positions — and exactly one rule that prevents that mixing from reaching forward in time. Self-attention is that path; the causal mask is that rule. Chapter 1 promised the FFN sub-layer would be the only thing we eventually swap for MoE; that promise relies on attention staying a fixed, minimal piece of the baseline, which is what we build here.

    Figure 2.3 — One \(T \times T\) slice of multi-head causal attention. The raw scores \(QK^{\top}/\sqrt{d_{\text{head}}}\) are added to a mask whose strict upper triangle is \(-\infty\); the row-wise softmax drives those entries to exactly \(0\) while the lower-triangular weights sum to \(1\) per row. Row \(t\) becomes a probability distribution over positions \(\{0, \dots, t\}\) only. Rendered via TikZ in the PDF version.

    Take the chapter-2 anchor mini-example: \(B = 2\), \(T = 8\), \(D = 16\). Pick \(n_h = 2\) attention heads, so \(d_{\text{head}} = D / n_h = 8\). One QKV projection (a single linear of width \(3D\)) plus one output projection (linear of width \(D\)) is all the parameter mass we need for this section — \(4 D^2 = 1024\) weights.

    Name the new symbols. We keep \(B, T, D\) from Section 2.2 and \(T_{\max}\) from the embedding's position table. Three new symbols enter: \(n_h\), the number of heads; \(d_{\text{head}} = D / n_h\), the per-head channel width (the constructor refuses any \(D\) not divisible by \(n_h\)); and \(M \in \mathbb{R}^{T \times T}\), the additive causal mask whose upper triangle is \(-\infty\) and lower triangle (including the diagonal) is \(0\). The mask is registered as a buffer, not a parameter — it moves to the right device but never receives a gradient.

    Table 2.3 — Tensor contract for one multi-head causal self-attention block. With the chapter-2 anchor (\(D=16\), \(n_h=2\), \(d_{\text{head}}=8\), \(T_{\max}=8\)), the block carries \(3 D^2\) QKV-projection weights and \(D^2\) output-projection weights.

    Failure mode — mask on wrong axis or applied after softmax — Past-output drift becomes non-zero; the diagnostic fires.

    The block's tensor equation reads in one line.

    \[ \mathrm{Attn}_h(x) \;=\; \operatorname{softmax}\!\left( \frac{Q_h K_h^{\top}}{\sqrt{d_{\text{head}}}} \;+\; M \right)\, V_h, \qquad M_{t,s} = \begin{cases} 0 & s \le t,\\ -\infty & s > t,\end{cases} \qquad Q_h, K_h, V_h \in \mathbb{R}^{B \times T \times d_{\text{head}}},\;\; d_{\text{head}} = D / n_h. \]

    The equation reads strictly left-to-right and the order matters: the mask \(M\) is added to the scaled scores before softmax, so the \(-\infty\) entries become exact zeros in the probability matrix — not small numbers that round to zero. Applying the mask after softmax (a common bug) would leave the probabilities renormalised over all \(T\) positions, then zero out the upper triangle without renormalising; the row sums would no longer equal one and gradients would still propagate from future tokens.

    The implementation in src/moe_from_scratch/ch02/attention.py packs the equation into a small nn.Module. Two utility moves are worth flagging: a single Linear(D, 3D) produces \(Q\), \(K\), \(V\) in one matmul (then chunk), and the \((B, T, D) \to (B, n_h, T, d_{\text{head}})\) reshape happens by view + transpose, so heads run in parallel without an explicit loop.

    class CausalSelfAttention(nn.Module):
    def __init__(self, d_model, n_heads, context_length):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_head  = d_model // n_heads
        self.qkv      = nn.Linear(d_model, 3 * d_model, bias=False)
        self.out_proj = nn.Linear(d_model,     d_model, bias=False)
        mask = torch.tril(torch.ones(context_length, context_length, dtype=torch.bool))
        self.register_buffer("causal_mask", mask, persistent=False)   # (T_max, T_max)

    def forward(self, x):                                              # (B, T, D)
        B, T, D = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)                         # each (B, T, D)
        # (B, T, D) -> (B, nh, T, d_head)
        split = lambda t: t.view(B, T, self.n_heads, self.d_head).transpose(1, 2)
        q, k, v = split(q), split(k), split(v)
        scores = (q @ k.transpose(-2, -1)) / math.sqrt(self.d_head)    # (B, nh, T, T)
        scores = scores.masked_fill(~self.causal_mask[:T, :T], float("-inf"))
        attn   = F.softmax(scores, dim=-1)                             # rows sum to 1
        out    = (attn @ v).transpose(1, 2).contiguous().view(B, T, D)
        return self.out_proj(out)                                      # (B, T, D)

# Diagnostic: perturbing input position T-1 leaves outputs 0..T-2 byte-identical.
y       = attn(x)
xp      = x.clone(); xp[:, -1, :] = torch.randn(*xp[:, -1, :].shape)
yp      = attn(xp)
assert torch.equal(y[:, :-1, :], yp[:, :-1, :])         # past cannot see future

    The section's diagnostic is the strongest possible end-to-end test of the mask: perturbing the input at position \(t\) must leave every output at positions \(s < t\) byte-identical. If the mask is missing, on the wrong axis, applied after softmax, or registered with the wrong shape, future-token information leaks back into the past and this diagnostic fires immediately. The example script under examples/ch02/ runs the chapter anchor batch through embeddings and then through CausalSelfAttention, perturbs only \(x[:, T{-}1, :]\) by a fresh random vector, and verifies that \(\max_{t < T-1} \lVert y_t - y_t' \rVert_\infty = 0\) exactly while the last-position drift is positive.
